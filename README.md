# AgriPulse: Web-Based Farm Management & Advisory Portal

## Project Overview
AgriPulse is a responsive web application designed for small-to-medium-scale farmers and agricultural extension workers. It centralizes farm data, optimizes resource planning, and provides real-time weather and pest outbreak alerts.

## Project Structure
- `server.js`: Node.js & Express backend API handling weather, plots, and expense logging.
- `package.json`: Backend dependencies and scripts.
- `client/`: React.js frontend application styled with Tailwind CSS.

## Getting Started

### Prerequisites
- Node.js & npm installed on your machine.

### Installation & Running

1. Install root dependencies:
   ```bash
   npm install
   ```

2. Install client dependencies:
   ```bash
   cd client && npm install
   cd ..
   ```

3. Run the development server (Backend & Frontend):
   ```bash
   npm run dev
   ```
